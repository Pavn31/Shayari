# Shayari.

> Some feelings are easier to write than they are to say.

A personal collection of **shayari, poetry, thoughts, and words** — written, remembered, and preserved in one place.

## ✦ About

**Shayari.** is a minimal editorial-style poetry website built to keep two kinds of words together:

- **My Shayari** — original writings and personal thoughts.
- **Famous Shayari** — memorable words from renowned poets.

The design is intentionally simple, quiet, and focused on the writing.
